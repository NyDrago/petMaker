# PetMaker (test build)

Requires the .NET 8 SDK.

    dotnet run

    or if i release compiled versions use that.

- "Create from image…" copies a PNG/etc. into your PetMaker folder and saves it.
- Select a pet, then "Run" (or double-click) to spawn it. Run it as many times as you like.
- On a pet: drag with left mouse to move, right-click to close.
- Use transparent PNGs; the window is exactly the image size, no borders.

Saved data: %APPDATA%/PetMaker (Win), ~/Library/Application Support/PetMaker (mac), ~/.config/PetMaker (Linux).
